# 🤖 Assistive Robotics Project

An assistive robotics project focused on using **computer vision, robotics, and intelligent automation** to help individuals maintain their daily routines and activities more independently.

## 💡 Motivation

This project was inspired by my desire to build a system that could help my autistic older brother maintain his daily routine and activities.

The goal is to explore how robotics and artificial intelligence can be used to provide practical assistance and reminders within a home environment.

## 🚀 Project Goal

The system is being designed to autonomously locate the user within a home environment and provide reminders about scheduled activities.

The proposed system combines:

- Autonomous robotics
- Computer vision
- OpenCV
- Camera-based user detection
- Intelligent automation
- Activity and reminder systems

## 🧠 Proposed System Workflow

```text
Scheduled Activity
        ↓
Robot Receives Task
        ↓
Autonomous Navigation
        ↓
Camera-Based Search
        ↓
Computer Vision
        ↓
User Located
        ↓
Reminder Delivered
```
